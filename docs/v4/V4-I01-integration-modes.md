# V4-I01 集成模式

配置项是 `aiditto.integration.mode`，环境变量 `INTEGRATION_MODE`。缺省和空白都是 `LEGACY_ONLY`。生产配置写死 `LEGACY_ONLY`。

| 模式 | 能否启动 | 行为 |
| --- | --- | --- |
| `LEGACY_ONLY` | 能 | 现有注册、问卷、V3 口味和 V3 学习保持原样。注销不擦 V4 行 |
| `V4_INTEGRATION_TEST` | 能 | 隔离测试可以投影画像，注销会走擦除协调。画像处理开关仍要单独打开 |
| `V4_SHADOW` | 不能 | 启动失败 |
| `V4_PILOT` | 不能 | 启动失败 |
| 其他字符串 | 不能 | 启动失败 |

这两个允许启动的模式都不会因此打开真实模型、真实向量同步、生产匹配、V4 反馈学习或策略自动激活。画像处理、Match Lab 和模型网关仍由它们原来的开关控制。没有用空实现假装影子匹配或试点已经可用。
