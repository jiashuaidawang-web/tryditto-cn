# V4-L02 全局匹配工作台

页面在 `/match-lab/global`。用户勾选当前工作区里的虚构画像，选择 G0 到 G4，然后调用真实的候选图构建和 `V4GlobalMatchingEngine`。权重没有改。

页面展示初始用户、推荐合格边、成功配对、未匹配人数、求解状态、求解时间、覆盖、安全违规、平均契合、最低契合和总权重。选择一个焦点用户后，只列出与这个用户有关的边，避免把所有边画成一张不可读的图。配对行在结果可继续时链到反馈页。
