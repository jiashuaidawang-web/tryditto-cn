## 指标

分母为 0 时结果为空。

| 指标 | 分子 | 分母 |
| --- | --- | --- |
| Recall@K | 前 K 名里的合法相关人 | 该寻求者的全部合法相关人，再对全体相加 |
| Precision@K | 前 K 名里标成相关的人 | 前 K 名里标成相关或不相关的人 |
| Precision 是否可报 | 上面的分母至少占检查槽位的一半，否则为空 | 检查槽位 |
| HitRate@K | 至少命中一个相关人的寻求者 | 至少有一个合法相关人的寻求者 |
| MRR | 第一名相关人的倒数名次之和 | 有合法相关人的寻求者数 |
| NDCG@K | 按等级的 DCG / IDCG | 有等级正例的寻求者数 |
| Candidate Coverage | 合法池非空且至少召回一人 | 合法池非空的寻求者 |
| 双向覆盖 | 反向也在对方列表里的有向边 | 全部召回有向边 |
| 候选数 P50/P95 | 每个寻求者的列表长度 | 寻求者 |
| 零候选比例 | 空列表的寻求者 | 全部寻求者 |
| 预算丢失 | 在前 50 名、不在前 10 名的合法相关人 | 合法相关人 |
| 路线贡献 | 最终被选中阶段里，按原因码归到该路的相关命中 | 命中的合法相关人 |
| 硬约束违规 | 进入结果后又通不过 `HardFilter` 的人数 | 计数，门槛是 0 |
| 过期 / 撤回召回 | 结果里 `current=false` 或已撤回的人数 | 计数，门槛是 0 |
| 越权读取 | 自由文本被写进向量的次数 | 本实现直接丢弃，测试期望是 0 |

未知标签不进 Precision 的分子或分母。未标注的人也不当成负例。召回命中率不解释成最终配对成功率。
