# V4-I02 快照契约

`shadow_run.input_document` 固定这次运行读到的业务输入。后续画像变化不回写它。

文档包含：运行编号、城市、cohort、周期、截止时间、策略版本、提交 SHA、用户编号、账号状态、画像版本、来源版本、生命周期代次、授权版本、输入哈希、性别、生日、年龄范围、身高、城市、匹配意向，以及特征码、状态和封闭枚举值。

不包含电话、邮箱、姓名、照片、自由文本职业和开场白原文。枚举值只保留不含自由文本的短标记。

`input_hash` 是这份文档的 SHA-256。`result_hash` 只在保留配对时覆盖配对；被拒绝、中止、过期或审计失败的结果使用空结果哈希，并且不写 `shadow_pair`。

后续 I03 如果读取快照，必须把状态限制为：

| 状态 | 本轮 |
|---|---|
| SHADOW | 唯一允许写入的配对状态 |
| PUBLISHED | 不产生 |
| CANCELLED | 不产生 |
| EXPIRED | 运行可以是 EXPIRED，但不留下可执行配对 |

`MatchFeedbackContext.production` 不启用。影子结果不能生成接受、拒绝或见面事件。
