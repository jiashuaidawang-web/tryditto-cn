# V4-L01 设计

五个页面：

1. 实验总览。按数据集版本筛选。冻结策略 E、B5、G2 各自指向自己的实验。冻结提交和分支 CI 列表分开。每条实验的样本量不与其他实验相加。
2. 用户画像。虚构列表按自我、偏好、行为、记忆四层展示。记忆层在没有单独写入时为空。编辑只用 `FeatureRegistry` 的合法值和领域里的三种特征状态。
3. 候选发现。可以选择冻结开发集或保留集的寻求者。页面先给初始池和合法资格，再比较 RRF、RRF + M02、完整合法池 + M02、完整画像短名单 + M02。`NO_ROUTE_SIGNAL`、截断、硬约束和证据不足保持原码。
4. 双向评分。选择两个人，调用领域引擎。单项证据可以展开。原始 JSON 可以折叠。修改一方软偏好后再算，前后结果并排。
5. AI 关系推理。回放确定性夹具。判断、互补、冲突、未知、拒绝和无依据推断分开。模型名是 `rule-echo-fixture`。真实模型状态是 `NOT_RUN`。

来源类型分开：

- `FROZEN_RESULT`：历史实验结果。
- `ENGINE_EXECUTED`：这次进程实际调用了引擎。
- `MODEL_REPLAY`：重放已有夹具输出。
- `ILLUSTRATIVE`：只说明状态，例如生产启用 NO-GO。

L02 和 L03 的页面没有做。
