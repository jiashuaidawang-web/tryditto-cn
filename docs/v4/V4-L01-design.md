# V4-L01 设计

五个页面：

1. 实验总览。目录、环境、生产 NO-GO、每条实验自己的样本量。
2. 用户画像。虚构列表、四层里当前注册表实际给出的分区、合法值、版本和摘要、两份画像的差异。
3. 候选发现。RRF、RRF + M02、完整合法池 + M02、完整画像短名单 + M02。未入选原因保留 `NO_ROUTE_SIGNAL`、截断和硬约束的区别。
4. 双向评分。选择两个人，调用领域引擎，修改一方软偏好后再算。前后结果并排。
5. AI 关系推理。回放确定性夹具。模型名是 `rule-echo-fixture`。真实模型状态是 `NOT_RUN`。

来源类型分开：

- `FROZEN_RESULT`：历史实验结果。
- `ENGINE_EXECUTED`：这次进程实际调用了引擎。
- `MODEL_REPLAY`：重放已有夹具输出。
- `ILLUSTRATIVE`：只说明状态，例如生产启用 NO-GO。

L02 和 L03 的页面没有做。
