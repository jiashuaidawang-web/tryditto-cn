# V4-M03 评估设计

这份设计在真实模型运行之前冻结。看到结果之后不降低门槛。

## 数据

`ReasoningDataset` 有 120 条合成关系，开发集 90，保留集 30。标签写在场景里，不由待测模型生成。同一寻求者下面的候选包含双向契合、单向、共同兴趣但需求冲突、兴趣不同但偏好满足、未验证互补、伪互补、沟通频率和主动性混淆、自身特征与伴侣偏好混淆、缺失、任意值条件、矛盾、缺失后的人格推断、诱导文本、硬约束和证据串向。

诱导文本只放在候选对象的爱好字段。它不应该出现在提示里。硬约束关系不应该产生推理调用。

允许多个合理类别。例如单向关系的反向可以同时有部分满足和冲突。空的可用列表对「任意值」和硬约束是正确结果。

## 真实模型门槛

在任何真实调用之前冻结：

- 通过校验后，证据支持判断的 precision 至少 0.90。分母是留在 `supportedMatches` 的判断数。分子是标签允许 `SUPPORTED_COMPATIBILITY` 的那些判断。
- 无依据判断进入可用列表的比例不超过 0.02。分母是可用判断数。分子是类别为 `UNSUPPORTED_INFERENCE` 或被校验器留下、但标签禁止的判断。可用列表不含 `unsupportedClaims`。

另外报告，但不作为可以事后下调的门槛：

- 方向正确率。分母是实际发起的方向调用。分子是身份和方向都正确且状态为 `COMPLETED` 的调用。安全拒绝单独计数，不放进这个分母。
- 契合、冲突的 precision 与关系级 recall。Recall 的分母是标签允许该类别的方向数，分子是其中至少有一条对应可用判断的方向数。
- 互补假设的关系级命中。潜在互补不算已验证契合。
- 证据归属错误数。分母是可用判断。一条引用若不属于这个方向的选择者偏好或目标自身特征，计为越权。
- 缺失识别和矛盾保留。分母分别是含缺失、含矛盾的关系数。
- 非法硬约束接受数和越权内容访问数。两者的接受数都必须是 0。
- C 方案前后的成对排序正确数和 NDCG。比较发生在同一寻求者的候选之间。分数更高才算赢；并列不算赢。NDCG 在并列时用候选 id 打破。
- P50、P95 延迟、token 和费用。费用拿不到就写不可得，不估计。

原始输出和校验后输出分开计。校验器自己的误接受率用 7 条对抗样本，不引用 P02 的 E4。

## 模型

候选是 LongCat-2.5、deepseek-flash、hy4-flash、qwen4-max。画像提取的优胜模型不自动成为这里的优胜模型。

没有 `M03_EXPERIMENT_KEY` 和名单内的 `M03_MODEL` 时，真实模型状态是 `NOT_RUN`。不读取生产密钥文件，也不把备用模型的结果算进实验。`NOT_RUN` 不阻塞离线工程。

规则回声夹具的数字写在评估报告的工程段。它们不能用来宣布真实模型通过了 0.90 或 0.02。
