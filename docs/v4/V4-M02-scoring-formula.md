# V4-M02 评分公式

版本 `compat-1`。运行前冻结。这些数是实验参数，不是产品规则。

## 权重

使用 `RelationshipTypes.Importance`：

- `SUPER = 3`
- `KINDA = 2`
- `NONE = 1`

没有 `PreferenceTarget`，和有一条重要性为 `NONE` 的偏好，不是同一件事。前者该方向没有偏好。后者按权重 1 参与已知分。

## 已知分和覆盖率

只把 `SATISFIED`（1）、`PARTIALLY_SATISFIED`（0.5）、`UNSATISFIED`（0）算进已知分。

```
knownScore = 已知满足值乘权重之和 / 已知权重之和
score = knownScore × 100
coverage = 已知权重之和 / (已知权重之和 + 未知权重之和)
```

已知权重为 0 时，score 为空，状态 `INSUFFICIENT_EVIDENCE`。可评估权重为 0 时，coverage 也为空。全部未知时 coverage 可以是 0，score 仍为空。不返回默认满分。

另外单独报告：未知权重、明确冲突权重、强偏好满足率、已比较特征数。强偏好满足率只看重要性为 `SUPER` 且已经比较过的项。没有强偏好时，这项为空，不当成 0。

`UNKNOWN` 不进入分子，也不被写成 0 或 50。`UNBOUNDED` 不是匹配。`WITHHELD` 不出现在明细里。`CONTESTED` 单独累计，不进入已知分和覆盖率分母。

分数和覆盖率分开。高已知分加低覆盖率仍然是低证据，不是高确定性契合。

## 聚合

两个方向分都有定义时：

1. 算术平均 `(scoreAB + scoreBA) / 2`
2. 调和平均 `2 × scoreAB × scoreBA / (scoreAB + scoreBA)`。双方为 0 时结果是 0。任一方向为 0 时结果是 0
3. 最低方向分
4. 几何平均。任一方向为 0 时结果是 0
5. 两个覆盖率都至少 0.60 时才保留调和平均，否则为空
6. 在第 5 条上，再要求每个存在强偏好的方向，其强偏好满足率至少 0.60

任一方向分未定义时，五种聚合都为空。

实验推荐门槛，同样事先冻结：最低方向分 60，最低方向覆盖率 0.60。不因为通过率去下调。

- B1 只看 `scoreAB >= 60`
- B2 看算术平均 `>= 60`
- B3 看调和平均 `>= 60`
- B4 看最低方向分 `>= 60`
- B5 要求覆盖率门控后的调和平均存在，并且最低方向分 `>= 60`
- B6 在 B5 上再加强偏好满足率门控

未定义的聚合排在已定义分数之后，包括排在 0 分之后。0 分是比较过并且不满足，不是证据不足。
