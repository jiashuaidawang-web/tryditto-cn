# V4-M03 排序增量

候选池和标签与冻结的 120 条关系相同。五个方案使用同一次 M02 决策：

| 方案 | 含义 |
| --- | --- |
| A | 只用 M02 分 |
| B0 | 服务端按 M02 行生成解释，分数不变 |
| B1 | 模型解释通过校验，分数仍用 M02 |
| C1 | `reasoning-experiment-1`。按支持与冲突条数加减，修正量 ±10，分数可以超过 100 |
| C2 | `reasoning-experiment-2`。去重、双向都成功、资格门控，分数限制在 0–100 |

成对比较要求左边的标注增益更高，且实验分严格更高。并列不算赢。NDCG 在并列时用候选用户 id 排序。特殊用户（id 不小于 90000）不进入这个排序组。证据不足和单向高分的推荐计数来自 M02 的 `recommendationEligible`。AI 没有改写推荐资格。

两个模型的五个方案得到同一组排序数字：

| 切分 | 成对正确 | NDCG | C1 改分的关系 | C2 改分的关系 | 无资格改分 | 证据不足仍推荐 | 单向高分仍推荐 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 全部 | 280/312 | 1.0 | 40 | 0 | 0 | 0 | 0 |
| 开发集 | 210/234 | 1.0 | 30 | 0 | 0 | 0 | 0 |
| 保留集 | 70/78 | 1.0 | 10 | 0 | 0 | 0 | 0 |

C1 改了 40 条关系的实验分，成对正确数和 NDCG 没有变化。M02 已经排错的 32 对没有被纠正。C2 在 M02 为 100 的相互满足关系上把加分钳回 100，状态是 `CLAMPED`，排序不变。资格不足的关系保持 `GATE_HELD`。LongCat 有 5 条因对侧 `REJECTED` 而让 C2 成为 `REJECTED`，分数仍是原来的 M02 分。

A、B0、B1 的分数相同。模型解释没有独立于 M02 的排序增量。本轮不选择 C1 或 C2 作为排序方案。AI 排序增益是 **NO-GO**。
