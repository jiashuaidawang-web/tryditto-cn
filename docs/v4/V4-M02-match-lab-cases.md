# V4-M02 Match Lab 案例

八个虚构案例的结构化结果在 `docs/v4/m02-match-lab-cases.json`。生成入口是 `CompatibilityCases.json()`。本轮没有前端。

每条都留下原始画像经过引擎后的对齐明细、两个方向、聚合、覆盖率、冲突和实验判断。判断不是产品决定。

| 案例 | 结果 | 实验判断 |
| --- | --- | --- |
| M02-C1 兴趣相似且偏好满足 | 100/100，覆盖率 1/1，调和平均 100 | 两个方向都有定义的已知分 |
| M02-C2 兴趣不同但偏好满足 | 100/100，覆盖率 1/1 | 兴趣交集不是偏好满足的条件 |
| M02-C3 A 高、B 低 | 100/25，算术平均 62.5，调和平均 40，最低分 25 | 只看 A→B 会误推荐 |
| M02-C4 双方中等 | 50/50，调和平均 50 | 低于冻结的 60 分实验门槛 |
| M02-C5 共同兴趣但强偏好冲突 | 0/0，8 条强偏好冲突 | 共同兴趣不能抵消冲突 |
| M02-C6 高分但覆盖不足 | 已知分 100/100，覆盖率 0.25/1，覆盖率门控后的调和平均为空 | 高已知分不是高确定性 |
| M02-C7 画像矛盾 | 可排序分数为空，明细是 `CONTESTED` | 矛盾不是 0 分或 50 分 |
| M02-C8 硬约束否决 | 状态 `HARD_VETO`，规则 `HARD_AGE`，可排序分数为空 | 不生成可供后续推理使用的画像明细 |

M02-C8 的解释明细里仍能看到偏好比较。发布出去的 `scoreAB`、`scoreBA` 和全部聚合都是空。
