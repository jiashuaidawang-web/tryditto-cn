# V4-I02 交给 I03

I03 还没有实现。本轮不接入真实反馈。

I03 之前必须另有用户侧授权来源，分别覆盖：

- 反馈学习。
- 个体学习。
- 群体评估。

`V4_SHADOW_TEST` 不提供这些授权。合成 `MatchFeedbackContext` 也不是用户授权。

I03 可以读取 `shadow_run` 作为当时的输入证据，但只能把 `pair_status = SHADOW` 当成影子记录。它不能把这些行改成 `PUBLISHED`，不能写入 `match`，也不能因为影子配对存在就生成接受、拒绝或见面事件。

正式 `MatchSnapshot` 至少要带：运行编号、关系身份、双方画像版本、双方生命周期代次、候选策略、评分版本、全局目标、双向分数、覆盖率、证据摘要、发生时间和状态。状态必须能区分 `SHADOW`、`PUBLISHED`、`CANCELLED`、`EXPIRED`。本轮只有 `SHADOW`。

另外两项仍是生产阻塞，不属于 I02 的完成范围：

- Qdrant 账号擦除执行器没有实现。外部任务保持 `NOT_RUN` 或 `FAILED`。
- Blossom 线程不能被安全取消。超时只丢弃结果。

业务画像与 M02 四对对齐特征的交集是 0。在这个契约补上之前，不能把影子配对数量当成推荐质量。
