# V4-I02 业务特征覆盖

领域测试对冻结映射和冻结对齐表做了直接比较：

| 项目 | 实测 |
|---|---|
| 已映射问卷特征 | 22 |
| M02 对齐目标 | 4 |
| 两边重叠 | 0 |
| 样例投影里可评分对齐 | 0 |

样例投影包含阅读、关系目标、筛选节奏、不愿提供学历、不限制身高和学历、年龄硬边界、性别硬边界。可评分对齐仍是 0。无对齐目标和合法但不可评分的特征都大于 0。

缺口来自两处：

- Onboarding 本身没有采集 pace、communication、social initiative、schedule 这四对。
- 已有 22 项映射没有一条指向 `FeatureAlignmentRegistry.v1`。

年龄和双向意向仍由 `HardFilter` 处理，没有降成软特征。未映射问卷保持未支持。业务画像因此不能支撑现有 M02 推荐资格。特征覆盖质量 NO-GO。

隔离集成测试用真实入驻接口写用户，用来确认入池、硬约束和“零推荐边”这条工程路径。它不改变上面的契约结论。
