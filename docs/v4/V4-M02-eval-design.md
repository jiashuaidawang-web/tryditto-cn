# V4-M02 评估设计

标签在评分函数之外指定。场景名决定等级，评分器不生成标签。开发集和保留集都使用这些对照，保留集改了哪一个维度承担不满足。这不是开放世界样本，也不能用来改门槛。

## 集合

110 条虚构关系。开发集 8 名寻求者各 10 条，共 80 条。保留集 3 名寻求者各 10 条，共 30 条。来源都是 `synthetic-fixture:v4-m02-eval`。

每个寻求者的 10 条覆盖：

| 场景 | 等级 | 设计 |
| --- | --- | --- |
| 双向强满足 | STRONG，增益 3 | 四个强偏好都精确满足 |
| 有证据的中等分 | WEAK，增益 2 | 两个精确、两个相邻，75 分 |
| 双向中等 | WEAK，增益 2 | 两个满足、两个不满足，50 分 |
| 单向 | ONE_WAY，增益 1 | 100 对 25 |
| 稀疏高分 | INSUFFICIENT，增益 0 | 已知分 100，一侧覆盖率 0.25 |
| 强偏好冲突 | CONFLICT，增益 0 | 四个强偏好都不满足，兴趣可以相同 |
| 硬约束 | HARD_VETO，增益 0 | 年龄区间双向失败 |
| 矛盾 | CONTESTED，增益 0 | 自身和偏好都是矛盾，不记 0 或 50 |
| 不公开后的其余项 | STRONG，增益 3 | 沟通习惯不公开，其余三项满足 |
| 对方没有偏好 | INSUFFICIENT，增益 0 | 一个方向有分，另一个方向没有偏好 |

兴趣相同的冲突、兴趣不同的强满足，用来和只看爱好的 V3 分对照。未标注的人不算负例。

等级增益：STRONG 3，WEAK 2，ONE_WAY 1，其余 0。

## 选择规则

只在开发集的 B2、B3、B4、B5、B6 里选择。成对排序正确数最高者胜出。正确要求较高增益的一边有严格更高的分数。同分或同为未定义，不算正确。

并列时依次看更低的单向误推荐、更低的证据不足误推荐、更高的强偏好冲突识别。仍并列则保留 B2 到 B6 名单中更早的方法。保留集只报告，不参与选择。

离线质量通过的条件也事先写定：选中方法的开发集成对正确数高于 B0，单向误推荐少于 B1，硬约束违规、未知被当成数字、不公开泄入明细都是 0。

调和平均是候选，不是预设赢家。门槛保持最低方向分 60、最低覆盖率 0.60、强偏好满足率 0.60。

## 召回和评分分开

实验 A 在完整合法池上评分。实验 B 只在 M01 冻结的 R1–R5、Top-10、Top-20、Top-50 上评分。M01 权重和挑战集不改。挑战保留集 Recall@20 的 7/45 继续作为召回结论，不因为本轮评分集上的数字被改写。
