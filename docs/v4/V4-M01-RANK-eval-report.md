# V4-M01-RANK 评估报告

正例是运行前写好的手写强匹配。开发集 8 人，保留集 6 人。两套人、两套取值。开发集理想值是 `slow/quiet/low/early`，爱好 `reading`。保留集理想值是 `steady/direct/steady/flexible`，爱好 `music`。干扰候选的完整画像全部相反，召回 Map 却和寻求者相同。隐藏强匹配的完整画像一致，召回 Map 为空。

M02 分数没有参与打标签。原 100 人回归、220 人挑战、8 条强匹配分离和 M02 评估集都没有重跑成新的证明。历史分离实验仍是 0/8、4/8、8/8。

每个方案只有 1 个寻求者。零候选比例的分母是 1。最终名额是 20。标签覆盖率是 20/20，因为返回的每个人都有手写标签。`other` 是单向或稀疏，既不算强匹配，也不算干扰负例。

## 完整池计数

开发集合法边 50，E 评分 50，推荐合格 8，证据不足 42。保留集合法边 58，E 评分 58，推荐合格 6，证据不足 52。无法评分的 4 人在两套集合里都是撤回、过期、年龄和历史配对，他们不进入评分。小集合的评分墙钟是 2 到 3 ms。全池成本见基准报告，不使用这 3 ms。

这 8 条和 6 条合格边与手写强匹配重合。重合只说明 M02 的推荐资格在这两份对照上和手写标签一致。它不是关系质量的真值，也不能把高分本身写成正例。
