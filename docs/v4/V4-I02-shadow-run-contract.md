# V4-I02 影子运行契约

`V4ShadowRunner.run` 只在 `V4_SHADOW_TEST` 执行。运行编号必须是 `[a-z][a-z0-9.]{0,40}`。

固定版本：

- 候选策略 `recall-rank-1`
- 图策略 `E_FULL_POOL`
- 评分策略 `compat-decision-1`
- 全局目标 `global-objective-g2-1`

其他版本直接拒绝，不求解。

顺序：

1. 获取会话级 advisory lock，类 13、键 1。它在任何用户行锁之前。注销仍是用户行然后类 11，两边没有反向等待。
2. 读取权威用户池并计算输入哈希。
3. 同一运行编号和同一哈希直接返回原记录。哈希变化不覆盖原记录。
4. 超过预算则拒绝，不建图。
5. 建完整候选图并求解。图不完整、超时或审计失败都不保留配对。
6. 在短事务里按用户编号锁定用户行，重读账号、授权、代次和哈希。变化则记 `EXPIRED`。
7. `ShadowPlanAudit` 独立重算。通过后才写 `COMPLETE` 和 `shadow_pair`。

并发上限是 1，不排队。第二个运行返回 `CONCURRENCY`，不写第二套可执行配对。

影子配对的 `pair_status` 只能是 `SHADOW`。没有把影子行转换成发布计划的方法。
