## 边界

这批标签和路线描述的是同一类关系：爱好重叠、同值自身特征、偏好指向对方自身、两条写明的跨特征规则。保留集换了取值，没有换关系类型，也没有用来调权重。它证明这套离线召回能找回自己的标注，不证明开放语料或真实 embedding 的质量。哈希向量没有参加这张表。
