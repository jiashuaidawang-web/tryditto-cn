# V4-F03 策略比较

比较的是合成观察里已经发布的匹配。每一行的双方接受、双方拒绝和其余标签都来自该策略自己的已发布样本。没有为未发布的配对填写接受、见面或继续交往。

真实策略提升是 `NOT_IDENTIFIED`。受控实验是 `NOT_STARTED`。重放另一套配对不能换成真实接受率会提高。

这三列要分开看：

- 数学目标：G1 最大化权重，G2 先人数再权重，G3 质量层，G4 公平。当前选中的离线目标仍是 G2，版本 `global-objective-g2-1`。
- 合成标签：上表只数已发布观察里的 Y1。
- 真实业务结果：没有。表里的接受数不是线上接受率。

F 是短名单对照。把 F 从样本里拿掉之后，它的已发布数是 0，不会被补成一个接受率。

策略提案的基线版本和候选版本都是 `global-objective-g2-1`，变更是 `no weight change`。状态可以是 `EVALUATED`，激活被拒绝。
