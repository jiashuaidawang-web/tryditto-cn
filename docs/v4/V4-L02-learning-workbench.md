# V4-L02 画像学习工作台

页面在 `/match-lab/learning`。信号来自 `FeedbackSignalClassifier`。提案来自 `ProfileLearningEngine.propose`，确认、拒绝和过期来自 `apply`。撤回来自 `retractDerived`。

确认和主动修改不是同一件事。确认只在提案所属用户本人调用 `decide` 时生效，另一个虚构用户会得到 `CROSS_USER`。待确认提案不进入评分。拒绝和超时不会变成未经确认的偏好。对方评价不写入本人自身事实。

确认之后，工作区画像版本增加。变更表列出确认前的特征和确认后仍在评分里的特征。被撤回的来源不再进入评分，其余特征保留。页面上的重新匹配使用新版本画像，并保留旧运行。分数变化旁边写明它不是真实关系质量提升。
