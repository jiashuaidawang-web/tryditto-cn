# V4-L02 反馈事件工作台

页面在 `/match-lab/feedback`。它从全局匹配的一对可继续结果打开账本。服务端先写 `MATCH_PUBLISHED`。双方各自有一组动作，动作名交给 `FeedbackLedger.append`，不在 React 里推进状态。

时间线给出事件编号、类型、行动者、发生时间、记录时间、来源、是否有效、因果事件和更正关系。投影给出双方响应、互相接受、见面安排、出席、争议、继续意愿、未知项和学习资格。

一方出席报告保持 `ONE_REPORTED_ATTENDED` 或在双方相反时保持 `CONTESTED`，不会升成双方确认。超时是 `EXPIRED`，不是拒绝。更正把原事件标成被取代，不由页面伪造一条系统事件。不是这对匹配的用户不能提交。
