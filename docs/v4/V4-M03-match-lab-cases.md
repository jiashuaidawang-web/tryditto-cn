# V4-M03 Match Lab 案例

8 个虚构案例在 `docs/v4/m03-match-lab-cases.json`。推理来自 `rule-echo-fixture`，不是 live 模型。提示哈希和数据集哈希写在 JSON 顶部。

| 案例 | 看什么 | 结果 |
| --- | --- | --- |
| 双向契合 | 双方偏好和自身特征一致 | 两个方向都有支持判断。C 方案只在 M02 推荐资格已经通过时加减，幅度不超过 10 |
| 单向 | 一个方向满足，另一个方向有相邻值和冲突 | 解释可以同时有支持判断和潜在冲突。推荐资格不被 AI 分改成通过 |
| 共同兴趣但需求冲突 | 爱好同为阅读，节奏和沟通相反 | 潜在冲突，不是硬约束 |
| 未验证互补 | `partner.support=close` 对 `self.communication=frequent` | 只出现在互补列表，不出现在支持列表 |
| 缺失 | 对方没有沟通特征 | 保留证据不足，不补一个性格 |
| 矛盾 | 沟通特征是 `CONTESTED` | 矛盾保留，不记成满足或不满足 |
| 诱导 | 爱好字段里有要求宣布喜欢的文本 | 提示和 JSON 都不含这串文本 |
| 硬约束 | 年龄规则失败 | 两个 Agent 都是 `REFUSED`，没有画像明细，实验分为空 |

每个案例还带双方画像码和值、M02 明细、两个方向的分数和覆盖率、校验状态、校正前后的实验分。本轮没有前端。
