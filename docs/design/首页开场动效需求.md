# 首页开场动效需求

来源：用户对 https://tryditto.com/ 冷启动前 20 秒的观察（2026-11-12）。这是用户点名最喜欢的部分，中文版首页必须复刻这段节奏。

## 原版时间线（用户实录）

| 时间 | 事件 |
|---|---|
| 约 1.4 秒 | 英文标题 `get a date next wednesday` 出现 |
| 紧接着 | iMessage 聊天框从下方滑上来 |
| 再过约 1.5 到 2 秒 | 鸽子从左侧画外飞入，嘴里衔着信封 |
| 之后持续 | 鸽子一直保持飞行动作 |
| 之后持续 | 背景三层风景一直向左做视差滚动 |

精确的毫秒数、缓动曲线、图层速度比，以 `docs/research/06-ditto-首页开场动效拆解.md` 的逐帧测量为准。

## 中文版要求

- 节奏照搬：先出标题，再滑上来聊天框，再让鸽子衔信飞入，之后飞行和视差持续循环。
- 标题本地化为中文，保留原版逐字或逐词出现的手法。具体文案待定，例如「下周三，去约会」。
- 鸽子衔信对应「飞鸽传书」。鸽子、信封和三层风景都要重新绘制，不得使用 Ditto 的原始素材。风景换成中国校园元素，例如教学楼、林荫道、操场。
- 聊天框沿用类 iMessage 的气泡样式，内容换成中文开场对话。
- 首屏在弱网下也要先出标题和聊天框，动画素材加载失败时不能白屏。
- 支持系统「减少动态效果」设置：开启时跳过飞入和视差，直接显示静态终态。
