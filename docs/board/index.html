Web App 登录前

app.tryditto.com 只接受学校邮箱（.edu / .ca），普通 Gmail 会被拒，回跳 /login?error=invalid_email。

入驻问卷全流程

新账号在 app.tryditto.com/onboarding 的真实走查，走的是学生路径，共 30 页，兴趣分支覆盖了 3 个（做饭、音乐、旅行），另外 5 个（阅读、健身、游戏、影视、美术）在「补充 · 资料编辑页」一组用已入驻账号补齐，8 个全覆盖。每页一张主截图，右侧是逐字文案和交互说明，下方是该页各交互状态。红框是中国版要删的题和最后一页的自动提交风险。没走到的分支见本节末尾。

问卷题库

来自 app.tryditto.com 前端代码（research/assets/ditto-app/questionnaire.json），尚未逐题与真实界面核对，核对结果见上方「入驻问卷全流程」。中国版决定：题干原文直译，删掉 8 道敏感题（划线标出），年级、渠道、身高、预算等选项换成国内说法。

Web App 登录后

已注册账号（职场流程）。登录后只有三个 Tab：Ditto / Where / You。单题编辑页和入驻问卷共用「对话气泡 + 胶囊选项」组件，这是复刻问卷的直接参照。

视觉共性：蓝色渐变 + 颗粒噪点背景、白色半透明毛玻璃卡片、手写体大标题、品红粉唯一强调色、白色线性图标。
